# PAI最終課題 Task05: 予測に基づくロボットアームのキャッチング

omnicampusアカウントID: 84500

落下するボールを2リンクロボットアームが**AIで軌道予測**してキャッチするタスク。
2次元簡易物理シミュレーション上で、75秒間に**25回キャッチ（成功率100%）**を達成。

## 実行方法
`Physical_last_assignment2.ipynb` を Google Colab で開き、上から順に実行。
出力: `/content/task05_catch2.mp4`（75秒 / MP4）

## 使用技術
- Python, numpy, matplotlib
- Google Colab
- 2リンク逆運動学（IK）によるアーム制御
- 最小二乗法による放物軌道予測（推論のみ・学習不要）

## AIの活用
直近サンプルから `y(t) = y0 + v0 t - 1/2 g t^2` を最小二乗フィットし、
未来のボール位置を予測してアームを先回りさせる（推論のみ）。

## 工夫点
- 予測に基づく先回り制御
- アーム先端高さの追従
- 接触判定によるキャッチ→保持
- 末尾余白(SAFE_MARGIN)による自然終了
